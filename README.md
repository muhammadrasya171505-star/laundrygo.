# laundrygo.
Identitas Proyek
- Nama proyek: LaundryGo --- Website Pemesanan Jasa Laundry
- Teknologi: HTML, CSS, JavaScript
- Tujuan: Membantu pelanggan melihat layanan, memperkirakan biaya,
  mengisi pesanan, dan meneruskan detail pesanan ke kasir melalui
  WhatsApp.
- Catatan kejujuran: Ringkasan interaksi AI di bawah disusun dari
  peninjauan kode dan konteks proyek, bukan transkrip kata demi kata.
  Sesuaikan dengan interaksi yang benar-benar dilakukan dan isi hasil
  pengujian berdasarkan praktik nyata.
